## 实施范围

| 路由 | 当前实现 | 实站状态 |
| --- | --- | --- |
| 首页推荐、关注、热榜、搜索 | 从当前已加载卡片提取一条标题、可得作者、原文链接及最多 240 字摘要，并明确显示为预览。 | 联验待执行 |
| 问答 | 在原生已加载且完整可见的回答中读取一条全文。直达回答路由要求 DOM 中存在对应回答。 | 联验待执行 |
| 专栏 | 读取原生标题、可取得的作者和发布时间、完整正文及原文。 | 联验待执行 |

阅读器包含独立顶部工具栏、左导航、正文和右目录。标题目录按可见正文生成，支持跳转、选中反馈和折叠。正文宽度有默认、较宽、全宽，浅色／深色及当前排版设置在本次打开期间有效。导航的后续功能已标注待接入。原生页面和状态恢复仍由 M01 生命周期负责。

富文本适配器从可见 DOM 建立白名单数据树，渲染器创建新的安全节点。标题、段落、列表、引用、代码、粗斜体和图注保留结构。安全链接仅允许 HTTP(S)，打开时省略 Referer，截断、登录墙及内容为空时保留原页。已解码图片仅绘制到 Canvas，未加载图片显示替代文本。正文从属的数据、样式、脚本及表单不会被原样注入，读取器无后台预取及主动知乎 API 请求。

### M02-L-R 入口避让修复

在 Edge `0.0.2` 的原生页截图中，两个入口同处右下角，知乎浮层部分覆盖了阅读按钮。用固定在右下角的合成原生按钮复现了包围盒交叠。`0.0.3` 仅通过 CSS 将项目入口移至左下角，原生浮层和层叠级别沿用原设置。 [脱敏实站局部截图](evidence/m02-l/edge-0.0.2-launcher-overlap.png)

`0.0.3` 构建 SHA-256 为 `dabe299440412d6591c0a5555775711f985139fd4d034e33a1b9fa362a382693`。本地构建、语法、单元与静态检查 10/10、正式产物 DOM 回归 24/24、历史探针 21/21 通过。在 Windows Chrome `157.0.8103.52` 和 Edge `157.0.4341.60` 的合成页面中，420、885、900、1200、1440 CSS px 均验证了两个按钮互不覆盖且均可用鼠标点击。Esc 后焦点返回阅读入口，420 CSS px 下正文区域无横向溢出，目录可以展开。

两端均通过仓库 WebDriver 合成回归。在 600、885、900、1200、1440 CSS px 验证入口避让和点击，并完成既有排版、目录、主题、滚动、焦点、连续进出、路由和访问限制回退检查。WebDriver 窗口的最小宽度限制了 420 CSS px 设置，该尺寸的检查使用 Playwright 视口。

Edge `0.0.2` 已获认可的人工实测结果沿用。Edge `0.0.3` 尚需补实站入口复测、阅读器整体和细节截图、窄窗口及缺失正文或异常回退。Chrome `0.0.3` 安装与实站矩阵待补。此前 HTTP 403 和「请求参数异常」的根因未明。

先完成日常 Chrome 同一首页的启停对照，再在独立 Chrome 和 Edge 配置核验 `0.0.3`，按 [M01 实机用例](M01-VALIDATION.md#原生访问对照与未完成实站用例) 联合验收。遇到 403、验证码、登录或网站安全限制即停止。

M01-L-R、联合实机验收及 Gate 01-V 保持 `BLOCKED`。双端实站通过且访问异常和其他阻断问题解决后可申请 Gate 01-V，Gate 确认后方可申请 M03。M03–M05 保持锁定。

# M03-R 实施建议

| 阶段 | 建议 | 验收证据 |
| --- | --- | --- |
| M02 | 保留按路由匹配可见正文的提取、结构化节点渲染、已加载图片和标题目录。补多图、图片失败、重复标题及缺正文夹具。 | 两端验证选中目标回答、无正文保留原页、列表只读摘要及入口避让。 |
| M03-A／B | 复用现有路由识别与预览模型。采集当前 DOM 已渲染的推荐、热榜和原生搜索结果。随有效列表根变动批处理，路由离开释放观察器。 | 覆盖列表挂载替换、滚动追加、空结果、同项重复、登录回退和恢复。 |
| M03-C | 用规范化类型与内容 ID 形成键值。存储必要元数据，保留顺序与当前位置。用户操作后导航到已知原生地址。用路由代数丢弃过期 DOM 更新，回答切换限当前可读 DOM。 | 快速切换、不同问题的相同展示标题、缺 ID、列表重渲染、回退与队列尾部。 |
| M04 | 先验证 GM 存储在两个知乎子域和多标签的行为，再设计版本字段、逐字段恢复、记录键及冲突策略。GM 监听作为失效通知，避免用整份快照覆盖并发更新。 | 两管理器行为、跨子域增删、旧版本迁移、损坏字段、重复事件、交叉写入及删除传播均需实测。 |
| M05 | 沿用固定依赖、可重复构建、安装源码哈希和双浏览器矩阵。对权限、DOM 副作用、入口互斥和退出回退保留自动检查。 | CI 构建指纹一致，正式扩展实站与离线回归分别保留证据。 |

**预计节省 2–4 人日，粗估。** 基于四组工序估算，复用路由与 DOM 适配约 0.5–1 日，沿用生命周期与用例脚手架约 0.5–1 日，沿用固定构建和测试工具约 0.5–1 日，现有上游缺陷与字段恢复用例约 0.5–1 日。按避免重做估算，未计真实 DOM 变体、未知访问异常或并发验证。[选型矩阵](ADOPTION-MATRIX.md) · [隔离实验](BENCHMARK-RESULTS.md)

以上供负责人审批。M03–M05 的实施日程取决于双浏览器实站、Gate 01-V 和技术选型审批。

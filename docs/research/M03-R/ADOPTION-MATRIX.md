## 负责人批准的技术决策

批准基线为 `dev` 的 `50599c0ff57922839d3d6c16c051067f8af05775`。评分及实测记录来自研究提交 `5e3f123b681d2abac597b429542bef180b93f5d8`。

| 决策 | 批准范围 |
| --- | --- |
| KEEP_CURRENT | 保留现有 DOM 提取、富文本节点渲染、核心生命周期、单文件构建及 CI。 |
| PARTIAL | 按需复用锁定上游版本中经过审计的 MIT 纯 DOM 选择器及必要字段，保留许可声明。 |
| REIMPLEMENT | 参考 Obsidian 的会话代数、过期状态保护与逐字段恢复策略，独立实现。 |
| DEFER | 暂缓引入 DOMPurify 和 Defuddle。 |
| REJECT | Mozilla Readability 全页替换、XIU2 整包及 Reader View 整包。动态观察继续沿用现有生命周期。 |

本轮研究覆盖 7 个外部仓库。批准的外部技术方向共 2 项，分别为 1 项局部复用和 1 项参考设计后独立实现。整体采用 0 项，现有实现保留 2 组，暂缓 2 项，拒绝整包或整体替换 3 项。新增正式运行时依赖 0 项。预计避免 2–4 人日重做，估算以四组后续工作为依据。[实施建议](IMPLEMENTATION-RECOMMENDATIONS.md)

后续模块在 PDT、架构、安全、许可证及模块授权范围内可自主完成常规选型与局部优化。新增运行时依赖、重大架构变更、权限扩张和许可证变更须单独批准。M03–M05 保持锁定，技术方向的落实以各模块获授权为前提。

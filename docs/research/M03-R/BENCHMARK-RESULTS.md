# M03-R 隔离实验

## 可复现条件

Windows，Node.js 24.19.0，Chrome 157.0.8103.52，Edge 157.0.4341.60。Playwright 隔离进程使用合成 HTML，拦截页面网络，直接读取固定快照源码与构建。每种提取热身 8 次，计时 40 次。包含 Readability 克隆与解析以及现有适配器的可见性检查和结构化抽取。输出形态不同，耗时用于这个夹具的工程取舍。DOMPurify 实验只检查配置功能。[执行脚本](benchmark.cjs) · [原始结果](benchmark.json)

| 场景 | 当前适配器 | Readability |
| --- | --- | --- |
| 普通专栏 | 两端完整正文 | 两端识别同一正文 |
| 指定回答 | 两端匹配目标 ID | 两端选择更长的另一个回答 |
| 折叠回答 | 两端不可用 | 两端返回文本 |
| 缺失正文 | 两端不可用 | 两端返回非空提取结果 |
| 热榜列表 | 两端仅返回预览 | 两端返回非空提取结果 |
| 受限页面 | 两端拒绝进入 | 两端返回文本 |
| 长专栏 | 两端完整正文 | 两端识别正文 |

| 长专栏 | 当前 p50 / p95（毫秒） | Readability p50 / p95（毫秒） |
| --- | ---: | ---: |
| Chrome | 2.5 / 3.1 | 8.7 / 10.2 |
| Edge | 2.2 / 3.3 | 10.8 / 13.8 |

当前完整构建 49,041 字节，gzip 12,862 字节。Readability 单文件 90,944／25,320 字节，DOMPurify Min 文件 31,131／12,439 字节。两端 DOMPurify 默认配置保留表单，窄白名单移除表单与表格并保留标题，增加的 gzip 大小约 12 KiB。该夹具覆盖功能边界，真实网站、第三方全量安全测试、Defuddle 实测和跨标签写入竞态均为 UNVERIFIED。
